Core Idea

把“生成 Agent”拆成一组可验证的 Prompt 接力。

每一步只做一件事，严格输出 JSON。前端拿到上一步结果后，直接作为下一步输入，最后形成可运行的岗位 Agent 工作台。

JSON in / JSON out
不是一个大模型凭空编 Agent，而是企业上下文、编制治理、岗位骨架和反馈规则共同生成 Agent。 这让我们能解释清楚架构，也方便队友分工：前端做状态流转，后端做 LLM 调用，Prompt 同学维护模板。
