Core Demo

市场部有员工 A 和 B：他们共用一个岗位 Agent，但各自拥有私有任务会话。

这个页面用来回答企业真实问题：如果需求越来越多、员工越来越多，Agent 会不会越建越乱？我们的答案是：部门共享岗位 Agent，个人保留会话隔离，正式发布需要权限审批。

Agent 是岗位资产，任务会话是个人资产，反馈规则审批后才变成部门资产。 所以不是人人养一堆自己的机器人，而是企业有一张 AI 员工编制表，需求先路由，权限再治理。

Judge Talk Track

评委问答口径

如果评委问“需求多了，Agent 会不会爆炸？”

不会。 我们不是一个需求生成一个 Agent，而是先做企业 AI 员工编制治理：单次任务直接交给已有 Agent，重复流程沉淀为 workflow / Skill，只有长期稳定职责才新建岗位 Agent。
