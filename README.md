# 企捏捏 OPC 在线 Demo 上线包

## 入口

- 本地入口：`index.html`
- 原型来源：`../prototype/interactive-roadshow.html`

## 对外口径

这是企捏捏的在线体验 Demo，目前为项目展示版，可体验“输入企业状态 -> 生成数字员工 -> 交办任务 -> 反馈进化”的核心链路。

## 推荐发布方式

1. 优先：推送到 GitHub 展示分支，使用静态预览链接。
2. 备选：将本目录拖入 Netlify Drop，生成临时 `netlify.app` 链接。
3. 兜底：保留本目录 zip 包，必要时现场本地打开。

## 检查项

- 电脑端可打开
- 手机端可打开
- `assets/tokens.css` 正常加载
- 数字员工头像正常显示
- 主流程能从生成员工走到交办与反馈
